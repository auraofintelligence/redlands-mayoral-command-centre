# Private campaign finance and public reporting

The sidebar's Budget and reporting page replaces the earlier Resources expense-only view. It retains the existing expense records and adds empty contributions and budget collections. Reading an older store makes those empty collections available in memory without rewriting the file, changing its revision or adding records.

Luke has no allocation to corflutes or signs and intends minimal paid social-media advertising. No budget figures, transactions, donations or deadlines are seeded. The public donations page currently provides enquiries only. Account readiness and the relevant ECQ steps are matters to verify before acceptance or expenditure.

## Record what happened

- Contribution types distinguish donations, non-cash gifts, Luke's own funding and loans. An enquiry, pledge, receipt awaiting review, acceptance, return and decline remain different states.
- An accepted contribution requires a positive amount, donor name, recorded eligibility review and agreement to named publication. This records the operator's review; the software does not certify eligibility.
- Budget entries are options, approvals or cancellations. An option does not authorise spending.
- Existing expenses retain planned, incurred, paid and cancelled states. New public-reporting fields do not alter older records until edited.

Keep donor addresses, receipts, banking/payment references, eligibility evidence and private notes in this private workspace. Ordinary volunteer labour is distinct from a donation. Non-cash gifts have a value but do not add cash to the account. The displayed totals describe recorded entries and are not a reconciled bank balance.

## Prepare a named public report

Luke's policy is to publish every accepted donation by name and amount, including below mandatory disclosure thresholds. Record the donor's informed agreement before acceptance. Mark each accepted contribution as reviewed for public reporting. A draft is blocked if an accepted contribution lacks that review or agreement.

Select any expense and budget entries for publication, and provide the intended public descriptions and payee labels. Private receipt and payment references are excluded. Returned contributions can be included when agreed and explicitly reviewed; unaccepted enquiries and pledges are excluded.

**Prepare public reporting draft** downloads a snapshot containing only allowed public fields. Review its accuracy and completeness with the public website's reporting page before publishing it. The approved snapshot replaces `data/campaign-finance-public.json` in the public website repository through its normal checked publication process. Never copy `private/operations.json` there. This action does not update the website or file ECQ returns automatically.

Private CSV exports and backups remain private. The public draft contains names approved for publication and still needs deliberate handling.
